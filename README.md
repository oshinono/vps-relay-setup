# vps-relay-setup

При push в `main` GitHub Actions публикует четыре статических Linux-бинарника и `SHA256SUMS` в [GitHub Releases](https://github.com/oshinono/vps-relay-setup/releases/latest). Используется встроенный `GITHUB_TOKEN`. Для скачивания без токена репозиторий должен быть публичным.

На Cloudflare Pages опубликуйте только `install.sh` в корне сайта. Секреты Cloudflare в GitHub не нужны. Скрипт устанавливает `relay-tui` в `~/.local/bin` (или `/usr/local/bin` при запуске от root). При каждом запуске сверяет SHA-256 с последним релизом и скачивает бинарник только при несовпадении. Для управления правилами установите и запустите системную копию от root.

На экране списка релеев отображается результат фоновой проверки обновлений. `U` повторяет проверку. Для установки обновления запустите `install.sh` с теми же правами, что и при установке.

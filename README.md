# vps-relay-setup

При push в `main` GitHub Actions публикует четыре статических Linux-бинарника и `SHA256SUMS` в [GitHub Releases](https://github.com/oshinono/vps-relay-setup/releases/latest). Используется встроенный `GITHUB_TOKEN`. Для скачивания без токена репозиторий должен быть публичным.

На Cloudflare Pages опубликуйте только `install.sh` в корне сайта. Секреты Cloudflare в GitHub не нужны. Скрипт устанавливает `relay-tui` в `/usr/local/bin` и запускает с правами root через `sudo`, если сам не запущен от root. При каждом запуске сверяет SHA-256 с последним релизом и скачивает бинарник только при несовпадении.

На экране списка релеев отображается результат фоновой проверки обновлений. `U` повторяет проверку. Для установки обновления снова запустите `install.sh`.
